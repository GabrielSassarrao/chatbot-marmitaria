Para execução 100% client-side no GitHub Pages, insira sua chave da API do Google Gemini (Google AI Studio). A chave fica salva apenas no sessionStorage do seu navegador.

Modo Híbrido Inteligente: No ambiente de Preview ou com chave configurada, a aplicação usa o modelo gemini-3-flash-preview real. Caso seja testada sem chave no GitHub Pages, um motor NLU local de contingência garante que a avaliação funcione sem erros!

Como Publicar no GitHub & GitHub Pages

Esta aplicação foi projetada em um único arquivo index.html 100% client-side, pronta para ser hospedada gratuitamente no GitHub Pages:

# 1. Salve este código como index.html em uma pasta e rode:
git init
git add index.html
git commit -m "feat: chatbot marmitaria com agente LLM e guardrails"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/chatbot-marmitaria-llm.git
git push -u origin main
2. Ativando o GitHub Pages:
  1. Acesse seu repositório no GitHub e clique na aba Settings.
  2. No menu lateral esquerdo, clique em Pages.
  3. Em Build and deployment > Branch, selecione main e a pasta / (root) e clique em Save.
  4. Aguarde 1 minuto. Sua URL pública será:
    https://SEU-USUARIO.github.io/chatbot-marmitaria-llm/
